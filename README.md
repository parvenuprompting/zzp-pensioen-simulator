# Zzp-Pensioen Simulator


![Status](https://img.shields.io/badge/status-prototype-blue)
![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Tech](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20Vanilla%20JS%20%7C%20SVG-informational)
![Privacy](https://img.shields.io/badge/privacy-100%25%20lokaal-success)
Modelleert pensioenopbouw bij onregelmatig zzp-inkomen: jaartabel of maandbedragen, fiscale jaarruimte (30% van winst, met verval), grafiek tot pensioenleeftijd en goede/slechte-jaren scenario's naast elkaar. Alles lokaal in de browser — geen servers, geen financiële data verstuurd.

**Live:** https://parvenuprompting.github.io/zzp-pensioen-simulator/

---

## Over deze build

Deze tool is gebouwd in de **PAC-fabriek** (Parvenu Autonomous Centre) en loopt onder het **Zero Trust Grow Kit-harnas**: elke stap is machine-geverifieerd, de mens heeft het laatste woord, en de geschiedenis is append-only. Onderdeel van de 400-ideeën-registratie van [tiendos-ideeenarchief.netlify.app](https://tiendos-ideeenarchief.netlify.app).
